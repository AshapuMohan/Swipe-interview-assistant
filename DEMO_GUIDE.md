# Demo Video Guide

This guide will help you create an effective 2-5 minute demo video for the Crisp Interview Assistant.

## Video Structure (Total: 3-4 minutes)

### 1. Introduction (20 seconds)
- Show the landing page
- Briefly explain what Crisp is
- Mention it's for the Swipe Internship Assignment

**Script:**
> "Hi! This is Crisp, an AI-powered interview assistant I built for the Swipe Internship Assignment. It provides a complete interview management system for both candidates and interviewers. Let me show you how it works."

### 2. Candidate Flow (90 seconds)

#### Resume Upload (20 seconds)
- Click "I'm a Candidate"
- Upload a resume (PDF or DOCX)
- Show file validation
- Demonstrate automatic data extraction

**Script:**
> "As a candidate, I start by uploading my resume. The system supports both PDF and DOCX formats and automatically extracts my name, email, and phone number."

#### Information Verification (15 seconds)
- Show the pre-filled form
- Mention validation
- Click "Start Interview"

**Script:**
> "The extracted information is pre-filled in the form. I can verify or edit it before starting the interview. The form includes validation to ensure all required fields are filled correctly."

#### Interview Process (55 seconds)
- Show the first question (Easy)
- Point out the timer
- Type a brief answer
- Submit and move to next question
- Show a Medium question with longer timer
- Demonstrate auto-submit by letting timer run out
- Show progress bar
- Complete the interview

**Script:**
> "The interview consists of 6 questions: 2 easy, 2 medium, and 2 hard. Each has a different time limit - 20 seconds for easy, 60 for medium, and 120 for hard questions. Watch the timer here. If time runs out, the answer is automatically submitted. The progress bar shows how far along I am."

#### Completion (10 seconds)
- Show the completion message
- Mention score and AI summary

**Script:**
> "After completing all questions, I receive my score and an AI-generated summary of my performance."

### 3. Data Persistence Demo (30 seconds)
- Refresh the page during an interview
- Show the "Welcome Back" modal
- Demonstrate resume functionality

**Script:**
> "One cool feature is session persistence. If I refresh the page or close the browser during an interview, I can resume right where I left off. Let me show you - I'll refresh the page... and there's the Welcome Back modal offering to resume my session."

### 4. Interviewer Dashboard (60 seconds)

#### Dashboard Overview (20 seconds)
- Navigate to Dashboard
- Show the statistics cards
- Point out the candidate table

**Script:**
> "Now let's look at the interviewer dashboard. Here we can see all candidates, their status, scores, and interview dates. The statistics at the top give a quick overview of total candidates, completed interviews, and those in progress."

#### Search & Filter (15 seconds)
- Use the search bar
- Demonstrate filtering by status
- Sort by score

**Script:**
> "The dashboard includes powerful search and filtering. I can search by name, email, or interview ID, filter by status, and sort by any column including score."

#### Candidate Details (25 seconds)
- Click on a candidate
- Show the detailed modal
- Point out the evaluation metrics
- Show AI summary

**Script:**
> "Clicking on a candidate opens a detailed view with their profile, interview responses, evaluation metrics across different skills, and an AI-generated summary with recommendations."

### 5. Technical Highlights (30 seconds)
- Briefly show the code structure (optional)
- Mention key technologies

**Script:**
> "Technically, this is built with React 19 and TypeScript, using Redux Toolkit for state management and Redux Persist for data persistence. The UI uses Ant Design components with custom styling. Everything is fully responsive and works great on mobile devices too."

### 6. Closing (10 seconds)
- Show the README or documentation
- Thank the viewers

**Script:**
> "The complete source code, documentation, and deployment guide are available in the GitHub repository. Thank you for watching!"

## Recording Tips

### Preparation
1. Clear browser cache and localStorage
2. Prepare a sample resume file
3. Close unnecessary browser tabs
4. Use a clean browser profile
5. Test your microphone
6. Practice the flow 2-3 times

### Recording Setup
- **Screen Resolution**: 1920x1080 or 1280x720
- **Recording Tool**: OBS Studio, Loom, or QuickTime
- **Browser**: Chrome or Firefox (latest version)
- **Zoom Level**: 100% (default)
- **Audio**: Clear microphone, no background noise

### During Recording
- Speak clearly and at a moderate pace
- Use smooth mouse movements
- Pause briefly between sections
- Highlight important features with cursor
- Keep energy and enthusiasm high
- Don't worry about minor mistakes

### Editing
- Trim dead space at start/end
- Add title card with project name
- Consider adding text overlays for key points
- Add background music (optional, keep it subtle)
- Export in 1080p MP4 format

## Key Points to Emphasize

### Must Show
✅ Resume upload and parsing
✅ Timed questions with different difficulties
✅ Auto-submit functionality
✅ Progress tracking
✅ Session persistence ("Welcome Back" modal)
✅ Interviewer dashboard
✅ Search and filter
✅ Candidate details view
✅ Responsive design

### Nice to Show
- Form validation
- Error handling
- Loading states
- Mobile view
- Different question difficulties
- Score calculation
- AI summaries

## Common Mistakes to Avoid

❌ Going too fast through features
❌ Not explaining what you're doing
❌ Skipping the persistence demo
❌ Forgetting to show the dashboard
❌ Not demonstrating search/filter
❌ Poor audio quality
❌ Too long (over 5 minutes)
❌ Not showing the timer working
