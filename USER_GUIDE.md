# Crisp Interview Assistant - User Guide

## For Candidates

### Step 1: Access the Interview Portal
1. Open the application
2. Click on **"I'm a Candidate"** on the home page

### Step 2: Upload Resume (Optional)
You have two options:

#### Option A: Upload Resume
1. Click **"Click to Upload (PDF/DOCX)"**
2. Select your resume file (PDF or DOCX, max 5MB)
3. The system will attempt to extract your information
4. Proceed to verification step

#### Option B: Skip Upload
1. Click **"Skip Upload & Enter Manually"**
2. Go directly to the information form

### Step 3: Verify Your Information
1. Review the extracted information (if uploaded resume)
2. Fill in or correct:
   - Full Name
   - Email Address
   - Phone Number
3. Click **"Start Interview"**

### Step 4: Complete the Interview
The interview consists of 6 questions with different difficulty levels:

#### Question Types & Time Limits
- **Easy Questions (2)**: 60 seconds each (1 minute)
  - Basic concepts and fundamentals
  - Green difficulty badge
  
- **Medium Questions (2)**: 120 seconds each (2 minutes)
  - Intermediate topics
  - Orange difficulty badge
  
- **Hard Questions (2)**: 180 seconds each (3 minutes)
  - Advanced concepts and system design
  - Red difficulty badge

#### During the Interview
- **Timer**: Watch the countdown timer at the top
- **Auto-Submit**: If time runs out, your answer is automatically submitted
- **Progress Bar**: Track your progress through the interview
- **Answer Box**: Type your answer in the text area provided
- **Submit**: Click "Submit Answer" to move to the next question

#### Important Notes
- ⏰ The timer starts automatically when a question appears
- 🔴 Timer turns red when 10 seconds or less remain
- 💾 Your progress is automatically saved
- 🔄 You can resume if you close the browser

### Step 5: View Results
After completing all 6 questions:
- See your final score
- Read the AI-generated summary
- Review next steps
- Return to home page

### Session Recovery
If you close the browser or refresh during an interview:
1. Return to the interview page
2. A "Welcome Back" modal will appear
3. Choose to:
   - **Resume Interview**: Continue where you left off
   - **Start New Interview**: Begin fresh (loses progress)

## For Interviewers

### Step 1: Access the Dashboard
1. Open the application
2. Click on **"I'm an Interviewer"** on the home page

### Step 2: View Candidates
The dashboard shows:
- **Statistics Cards**: Total candidates, completed, in-progress, pending
- **Candidate Table**: List of all candidates with details

### Step 3: Search & Filter
#### Search
- Use the search bar to find candidates by:
  - Name
  - Email
  - Interview ID
  - Position

#### Filter
- Click column headers to sort
- Use filter dropdowns for:
  - Status (Pending, In Progress, Completed, Rejected)
  - Position type

#### Sort
- Click any column header to sort
- Click again to reverse sort order
- Sortable columns: Name, Score, Interview Date

### Step 4: View Candidate Details
1. Click on any candidate row or "View Details"
2. Modal opens with:
   - **Profile Information**: Name, email, position
   - **Interview Details**: ID, date, status
   - **Evaluation Metrics**:
     - Technical Skills
     - Problem Solving
     - Communication
     - Cultural Fit
   - **AI Summary**: Recommendations and feedback
   - **Interviewer Notes**: Additional comments

### Step 5: Take Action
From the candidate detail modal:
- **View Resume**: Click to download/view resume
- **Evaluate Candidate**: Assess the candidate
- **Close**: Return to dashboard

## Tips & Best Practices

### For Candidates
✅ **Before Starting**
- Prepare your resume (PDF or DOCX)
- Ensure stable internet connection
- Find a quiet environment
- Have your contact information ready

✅ **During Interview**
- Read questions carefully
- Watch the timer
- Type clearly and concisely
- Don't panic if timer runs out
- Answer what you know

✅ **After Interview**
- Review your score
- Read the AI feedback
- Note areas for improvement

### For Interviewers
✅ **Best Practices**
- Review candidates regularly
- Use search to find specific candidates
- Read AI summaries for quick insights
- Check evaluation metrics
- Compare scores across candidates

✅ **Evaluation Tips**
- Consider all metrics, not just score
- Read actual interview responses
- Look for consistency in answers
- Note communication quality
- Review technical accuracy

## Troubleshooting

### Resume Upload Issues
**Problem**: Resume won't upload
- ✓ Check file format (PDF or DOCX only)
- ✓ Ensure file size is under 5MB
- ✓ Try a different browser
- ✓ Use "Skip Upload" option

**Problem**: Information not extracted
- ✓ This is normal - extraction is limited
- ✓ Manually enter your information
- ✓ Verify all fields before starting

### Interview Issues
**Problem**: Timer not working
- ✓ Refresh the page
- ✓ Check browser compatibility
- ✓ Clear browser cache

**Problem**: Can't submit answer
- ✓ Ensure you've typed something
- ✓ Wait for timer to run out (auto-submit)
- ✓ Refresh and resume session

**Problem**: Lost progress
- ✓ Return to interview page
- ✓ Click "Resume Interview" in modal
- ✓ Your answers are saved automatically

### Dashboard Issues
**Problem**: Candidates not showing
- ✓ Refresh the page
- ✓ Clear browser cache
- ✓ Check if any filters are applied

**Problem**: Search not working
- ✓ Clear search box and try again
- ✓ Check spelling
- ✓ Try searching by different field

## Data & Privacy

### What We Store
- Candidate information (name, email, phone)
- Interview responses
- Scores and evaluations
- Session data

### Where It's Stored
- **LocalStorage**: All data stored in your browser
- **No Server**: No data sent to external servers
- **Privacy**: Data stays on your device

### How to Clear Data
1. Open browser developer tools (F12)
2. Go to Application/Storage tab
3. Clear LocalStorage
4. Refresh the page
